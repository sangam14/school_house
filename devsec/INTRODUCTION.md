# DevSecRelAI — Introduction

DevSecRelAI adapts the School House site to teach secure development, DevSecOps, and AI-assisted security practices.

This folder will host initial DevSecRelAI lesson drafts and exercises. Add more lessons under devsec/ as Markdown files; they will be curated into the site during the content pipeline.

Planned lessons:
- Secure coding fundamentals
- Threat modeling for web apps
- Using AI for security triage
- CI/CD hardening and secrets management
