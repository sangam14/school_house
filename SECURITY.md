# DevSecRelAI Security Policy

This project is a security-focused fork of elixirschool/school_house. Security reports are welcome.

Reporting a Vulnerability

Please open a private issue or email security@your-domain.example with:
- A short summary of the issue
- Steps to reproduce
- Impact and affected versions
- Any suggested mitigations

Response

The maintainers will triage and respond within 72 hours. For urgent, high-severity issues include "CRITICAL" in the subject.

Disclosure

We follow coordinated disclosure and will work with reporters to fix vulnerabilities before public disclosure.
